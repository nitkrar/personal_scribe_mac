Step 11 says “Paths to cover: ... model load failure” without a concrete failing test or mapping rule ([PLAN_03_transcription.md](/Users/nitinkum/Projects/nitkrar/whisper_flow/plans/week1/PLAN_03_transcription.md#L670)). Since Plan 03 explicitly bypasses `downloadAndLoad` and takes ownership of download/staging itself ([PLAN_03_transcription.md](/Users/nitinkum/Projects/nitkrar/whisper_flow/plans/week1/PLAN_03_transcription.md#L22), [PLAN_03_transcription.md](/Users/nitinkum/Projects/nitkrar/whisper_flow/plans/week1/PLAN_03_transcription.md#L33), [PLAN_00_common-final.md](/Users/nitinkum/Projects/nitkrar/whisper_flow/plans/week1/PLAN_00_common-final.md#L558)), the model artifact source also needs an immutable revision.

Plan 00 requires hermetic path usage through `PSConfig.testingBaseDirectoryOverride` ([PLAN_00_common-final.md](/Users/nitinkum/Projects/nitkrar/whisper_flow/plans/week1/PLAN_00_common-final.md#L418), [PLAN_00_common-final.md](/Users/nitinkum/Projects/nitkrar/whisper_flow/plans/week1/PLAN_00_common-final.md#L862)).
