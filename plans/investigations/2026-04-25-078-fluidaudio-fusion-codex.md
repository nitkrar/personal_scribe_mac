# 078 FluidAudio offline diarization+ASR fusion

- Verdict: neither. FluidAudio ships offline ASR and offline diarization as separate APIs/CLI flows, not a fused speaker-labeled-transcript pipeline. The README’s ASR quick start uses `AsrManager.transcribe(...)`; the offline diarization quick start uses `OfflineDiarizerManager.process(...)` (.build/checkouts/FluidAudio/README.md:269-330). The API reference also documents them as separate managers with separate methods/results (.build/checkouts/FluidAudio/Documentation/API.md:37-72,172-203). The shipped `fluidaudiocli process` command is diarization-only: offline mode constructs `OfflineDiarizerManager`, calls `manager.process(...)`, and outputs `segments`/speaker counts, with no ASR call or transcript field (.build/checkouts/FluidAudio/README.md:511-516; .build/checkouts/FluidAudio/Sources/FluidAudioCLI/Commands/ProcessCommand.swift:153-233). FluidAudio therefore does not ship fused diarization+ASR; we would be inventing the fusion [inference].

- Data shape: there is no in-library manager-to-manager exchange type [inference]. `OfflineDiarizerManager.process(audio:[Float])` / `process(URL)` returns `DiarizationResult`, carrying `segments: [TimedSpeakerSegment]` plus optional `speakerDatabase` and `timings` (.build/checkouts/FluidAudio/Sources/FluidAudio/Diarizer/Offline/Core/OfflineDiarizerManager.swift:91-119; .build/checkouts/FluidAudio/Sources/FluidAudio/Diarizer/Core/DiarizerTypes.swift:121-165). `AsrManager.transcribe(_ [Float]|URL|AVAudioPCMBuffer)` returns `ASRResult { text, confidence, duration, processingTime, tokenTimings }` (.build/checkouts/FluidAudio/Sources/FluidAudio/ASR/Parakeet/AsrManager.swift:307-355,419-457; .build/checkouts/FluidAudio/Sources/FluidAudio/ASR/Parakeet/AsrTypes.swift:41-111).

- Timing note: the public ASR result exposes token timings, not word timings (.build/checkouts/FluidAudio/Sources/FluidAudio/ASR/Parakeet/AsrTypes.swift:41-46,94-111). Word timing construction exists only as an internal helper, `buildWordTimings(from:)`, inside vocabulary rescoring (.build/checkouts/FluidAudio/Sources/FluidAudio/ASR/Parakeet/SlidingWindow/CustomVocabulary/Rescorer/VocabularyRescorer.swift:165-218). So option (ii) is not a shipped public pattern as stated [inference].
