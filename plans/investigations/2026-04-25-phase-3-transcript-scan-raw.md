## Methodology recap

The scanner reads each Claude Code session JSONL in
`~/.claude/projects/-Users-nitinkum-Projects-nitkrar-personal-scribe/`, filters
to `type == "user"` records, strips system-reminder / hook / command auto-injected
content, excludes `tool_result` blocks (those are tool output, not user-typed),
and runs 38 case-insensitive regex patterns against the remaining real user-typed
text. Per-session it counts user turns and turns matching ANY pushback pattern.

The output below was generated with the cap on samples-per-pattern lifted, so
**every** matching context appears (not just 3 per pattern).

The 25 sessions covered span 2026-04-18 → 2026-04-25 in the Ninimma project
working-directory tree.

## Cross-pattern themes (analyst notes)

### Theme A — Repetition signals

The combined `again,` (13) + `you_keep` (5) + `i_dont_know_why` (2) + `you_keep_going` (1) + the qualitative *"every agent keeps talking like…"* and *"every time"* phrasing show that a non-trivial fraction of pushback is **the same correction being delivered more than once**. This is structurally distinct from a fresh course-correction and signals memory-load gaps rather than first-time bad judgment.

### Theme B — Drift mid-feature

`wait` (3) + the `f5605899 turn=35` *"wait what notes feature are we building"* + `c9168194 turn=41` *"Why do you keep focussing on symptom not root cause"* + `f5605899 turn=70` *"and you didn't find it after 3 attempts?"* show the user catching the agent **after work is already in motion**, indicating the front-loaded alignment phase isn't holding.

### Theme C — Test-fluff cluster

`useless` (22) + `tautology` (6) + `fluff` (6) + `screw_the_test` (1) cluster heavily in session `35834045` (the Apr 23-24 night dead-test sweep where 1,360 lines were pruned). Most are codex agent-output strings classifying tests, not direct user pushback — but the sheer density confirms the bug-fossil pattern at scale.

### Theme D — Over-complexity reflex

`simpler` (23) + `over_engineer` (4) + `over_complicate` (1) + `no_need` (7) + `we_dont_need` (1) + `thought_simple` (1) = ~37 hits where the agent's default was too much. Two memorable sub-cases:
- **Mute-system-audio (`5a59eb5e`)**: 4 separate "simpler" mentions in one session, plus `over_engineering again`, walking codex from CoreAudio HAL down to AppleScript over multiple rounds.
- **#016 RAM-aware (`c765cbed turn=24`)**: *"I thought this would be a simple test file of mocking memory and checking if it picked well"* — caught after 8 tests for a 3-line policy.

### Theme E — Architecture pivots caught at runtime

- `c765cbed turn=8/9` *"why are we implementing labels in code? don't we have a model registry"* — caught the bug-007 architecture before the second commit shipped.
- `d3537d8b turn=15` *"why do we have 2 snapshot systems again for same thing, I've repeatedly asked for centrally managed [SoT]"* — caught the #072 split that existed for weeks.
- `c9168194 turn=41` *"Why do you keep focussing on symptom not root cause"* — symptom-fixing reflex.
